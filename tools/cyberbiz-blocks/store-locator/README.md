# 官網據點列表 block

- Cyberbiz 匯入檔：`block.html`
- 公開資料 API：`GET https://platform.rueisiang.com/api/public/store-locator`
- 管理入口：平台「通路管理」→ 櫃點 →「官網據點資料」

API 只公開 `scope_kind = store`、營業中、未封存，且已填地址、縣市、類型與台灣 SVG 圖釘 X/Y 的通路。列表依 SVG 的 Y 值由北到南排序；儲存的圖釘位置使用 SVG 座標（X 475–840、Y 245–960），不是經緯度。Block 直接把每個圖釘的尖端 `(0, 0)` 放在 API 提供的 `(pinX, pinY)`，祖先圖層不額外平移；不需要扣圖釘寬高的一半，hover／選取縮放也維持相同尖端錨點。顯示用 viewBox 為 `475 245 425 715`（右界 900），替最大 X=840 保留右側空間容納圖釘與點擊區域；手機版 SVG 限制在容器寬度內，避免寬度溢出後被裁切。

官網圖片可選媒體庫 image ID（公開網址由既有 `cdn.rueisiang.com` 圖片 CDN 提供）或公開可讀取的 HTTPS 圖片網址。地址、營業時間、電話、樓層位置、分類與文案由通路資料提供；列表標題由「縣市＋通路名稱」組成，地圖標籤使用通路名稱。Google Maps 選取地點時會自動帶入地址與可辨識的縣市。

據點 JSON 不另存 CDN 作為第二份資料來源。API 是 D1 的唯讀投影，回應允許客戶端快取 60 秒；對這種小型、低頻變更的清單，不值得再維護一份 CDN JSON。媒體圖片則繼續由現有 CDN 分發。

通路管理可用 Google Maps 搜尋地點，選取後自動帶入 SVG X/Y 並顯示換算結果，仍可在下方手動微調；按儲存才保存 SVG X/Y，不保存經緯度。換算採用本島估算範圍（經度 120–122.1、緯度 21.9–25.3）；超出範圍會清空 X/Y，地址無法辨識縣市時會清空縣市，避免沿用上一個地點的資料。
