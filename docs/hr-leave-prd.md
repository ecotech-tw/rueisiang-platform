# 執行 PRD：月度人工假勤登記

## 1. 目的

本文件只定義薪資結算前的「月度人工假勤登記」。日常請假申請改由 [HRIS 申請與審核](./hr-request-center-prd.md) 處理；月度人工登記保留給人工核定的薪資調整與歷史資料，不是申請中心的第二個入口。

## 2. 不包含

- 本頁的員工自行提出請假申請
- 本頁的主管線上核准請假
- 年度假別額度自動產生
- 剩餘假數自動計算
- 假勤行事曆
- 請假流程與簽核紀錄

## 3. 導覽

假別主檔與月度人工登記分開：

```text
HRIS
├─ 出勤
│  └─ 假別管理
└─ 薪資
   └─ 薪資結算
      └─ 月度資料登記
         └─ 假勤紀錄
```

月度資料登記集中提供 HR 輸入假勤與時薪工時；出勤管理只提供出勤與假勤的查看入口。薪資結算讀取該月份的有效月度資料。日常請假由申請中心保存核准區間，不能在兩個入口重複登記同一筆扣款。

## 4. 登記 UI

```text
月份：[2026 年 8 月]
員工：[王小明                  ▾]

日期          假別       給薪比例    時數       扣款金額    備註
2026-08-05    特休       100%        8.0 小時      0 元
2026-08-12    病假        50%        4.0 小時  HR 輸入金額
2026-08-13    無薪假       0%        4.0 小時  HR 輸入金額

[新增假勤] [儲存]
```

欄位：

| 欄位 | 必填 | 說明 |
|---|---:|---|
| 員工／任職 | 是 | 關聯有效任職 |
| 日期 | 是 | 必須位於選定月份 |
| 假別 | 是 | 從預設假別清單選擇，也可由 HR 新增自訂假別 |
| 給薪比例 | 是 | 0～100%，例如 100%、50%、0% |
| 時數 | 是 | 0.5 小時為單位 |
| 扣款金額 | 是 | HR 依當月人工核定結果輸入，金額以整數元保存，不可為負數 |
| 備註 | 否 | 補充說明 |

同一員工同一天允許分開登記不同假別，但相同假別不可重複重疊；總時數不得超過當日可登記工時。

## 5. 統計

提供月份與年度統計：

- 各員工各假別的登記筆數
- 已請日期數
- 已請總時數
- 各給薪比例合計
- 全體員工彙總

第一版顯示「已登記數量」，不顯示「剩餘假數」，因為尚未建立年度額度與遞延規則。假別名稱以預設清單維持統計一致，也允許 HR 新增自訂假別。

## 6. 薪資關係

給薪比例不是只有有薪／無薪二分法：

```text
100% → 該假勤時數全額給薪
50%  → 該假勤時數給付一半
0%   → 該假勤時數不給薪
```

- 假勤類型主檔可以設定預設給薪比例。
- 每月人工登記時可以覆寫該筆給薪比例。
- 第一版不依工作地點或標準工時自動推導扣款；HR 直接輸入該筆人工核定的扣款金額。
- 給薪比例保留作為假別與統計資訊，也可協助 HR 核對扣款，但不自動覆蓋人工扣款金額。
- 月薪、日薪與時薪都由月度假勤登記的扣款金額直接納入薪資結果。
- 扣款金額以整數元保存，假勤時數仍以 0.5 小時為單位保存。
- 假勤資料或人工扣款金額修正後，薪資必須重新試算。
- 結帳後修正使用薪資調整，不修改原結帳結果。

## 7. 權限與歷史

- 只有全平台 HR 管理者可以新增、編輯與統計。
- 保存建立者、建立時間、修改者與修改時間。
- 扣款金額修改時保存原金額、新金額、修改原因、修改者與修改時間。
- 薪資結帳前可以修改當月資料。
- 結帳後不得直接修改原紀錄，改用薪資調整流程。

## 8. UI 原則

- 使用月份、員工、假別與給薪比例篩選。
- 表格支援內部捲動與手機版 `data-label`。
- 本頁不提供申請、送審與核准按鈕；申請流程使用獨立的 HRIS 申請中心。
- 不把假勤資料塞進員工基本資料頁。
