# 執行 PRD：特殊上班日規則

## 1. 目的

特殊上班日用來建立可重複套用的命名規則，並將規則套用到指定員工的指定日期。規則主檔與日期套用紀錄分開保存；日期套用只保存規則、人員、日期與補貼數量，重新試算時解析目前規則設定，已結算薪資則保留當次計算明細。

範例：

```text
常駐規則主檔：夜間進／撤櫃

有需要時才執行指派：
→ 員工：王小明、李小華
→ 日期：2026-08-05、2026-08-12
→ 補貼數量：各日期由 HR 登記

規則設定可以保留變更歷程供稽核，但日期套用不固定綁定某一版。
```

建立規則主檔時不選員工、不選日期；員工與日期只在「指派」時選擇。

## 2. 導覽

```text
HRIS
└─ 出勤管理
   └─ 特殊上班日
```

特殊上班日放在出勤管理，因為它首先定義日期的出勤性質；薪資結算讀取規則並計算金額。

## 3. 頁面結構

```text
特殊上班日
├─ 規則主檔
└─ 日期套用紀錄
```

### 規則主檔

列表顯示：

- 規則名稱
- 適用期間
- 已指派人數／日期摘要
- 薪資方式
- 加班設定摘要
- 啟用／停用狀態

操作：

- 新增規則
- 建立新版本
- 解除最新版本
- 刪除尚未納入薪資試算的規則
- 停用規則
- 套用到員工日期

規則設定保留變更歷程；目前規則變更或解除後，日期套用在下一次試算會使用目前仍有效的設定，不回頭固定某一版。規則及其日期套用只要尚未納入任何薪資試算版本即可刪除；刪除規則時一併移除這些尚未進入薪資歷史的日期套用。已納入薪資試算版本的規則不可刪除，只能停用，以保留來源與薪資明細的可追溯性。解除最新版本會回到建立該版本之前的狀態：該版本沒有薪資依據時直接移除，版本數與版本編號一併退回；薪資來源快照或薪資明細記錄過該版本，或該版本涵蓋的日期已有套用納入薪資試算時，保留為已解除版本；這類版本所屬的規則也不可刪除，即使當初的套用後來被改到別的規則。被移除的版本內容會寫入稽核紀錄。已結算薪資不受影響。

### 日期套用紀錄

列表顯示：

- 員工
- 日期
- 使用規則名稱與目前設定版本
- 固定每小時金額／倍率
- 補貼數量
- 套用者與套用時間
- 是否已納入薪資試算版本

日期套用紀錄可由出勤設定寫入者編輯規則、人員、日期與補貼數量；同一人員同一天仍只能保留一筆。列表可依人員、員工編號、規則、日期、日期區間與薪資試算狀態篩選。尚未納入薪資試算的日期套用可以刪除，刪除時須帶上畫面上看到的規則、人員與日期，與目前資料不符即拒絕；納入後不可刪除，但仍可編輯以供下一次試算使用。編輯後重新試算會使用新設定，已結算薪資明細不會被改寫。停用但仍有有效版本的規則，其既有紀錄可以維持原規則調整日期或補貼，但不能改套到另一個停用規則。

## 4. 規則欄位

| 欄位 | 必填 | 說明 |
|---|---:|---|
| 規則名稱 | 是 | 例如「夜間進／撤櫃」 |
| 適用對象 | 否 | 規則主檔不設定；於指派時選擇員工／支援人員 |
| 適用期間 | 是 | 規則設定的生效期間；日期套用本身不保存版本，結算解析目前規則 |
| 薪資方式 | 是 | 先依當日底薪計算特殊日應發總額，薪資明細只列特殊日應發總額減去原本薪資的差額 |
| 固定金額 | 否 | 以每小時計算 |
| 倍率 | 否 | 依確認的薪資公式計算 |
| 特殊日加班費級距 | 否 | 可依加班時數設定倍率或固定每小時金額；未設定時沿用一般加班規則 |
| 補貼項目 | 否 | 可設定多筆，例如夜間補貼、伙食補貼；套用日期時再填寫本次數量 |
| 備註 | 否 | 補充說明，可留空 |

特殊日加班費級距以 0.5 小時為單位保存，前端以累計加班時數的半開區間設定，起始含、迄止不含；例如 0.0～2.0 小時使用總倍率 150%，2.0 小時起固定每小時 NT$350。最後一級迄止留空代表從起始時數起不限時數；級距不可重疊或留空段。未設定級距時，核准加班沿用員工／公司加班規則。

固定金額與倍率的實際使用方式必須符合已啟用的薪資規則，不由前端自由組合出未定義公式。

## 5. 指派流程

規則主檔建立或維護時不指定員工與日期；有需要時從規則列按「指派」：

```text
選擇目前啟用的規則
→ 選擇一位或多位員工／支援人員
→ 選擇一個或多個日期
→ 輸入各日期補貼數量
→ 預覽
→ 套用
```

套用畫面提供：

- 員工複選
- 日期複選
- 每個員工／日期的補貼數量
- 預計影響人數與日期數
- 已存在套用紀錄提示

補貼數量：

- 可輸入 0 或正整數。
- 不設上限。
- 數量不是固定由規則主檔決定，套用時可依員工與日期輸入。

## 6. 計薪規則

- 特殊上班日先依當日正常本薪計算應發總額；本薪保留原本金額，特殊上班日明細只列「特殊日應發總額 − 原本薪資」的差額。
- 固定特殊薪資以每小時計算。
- 加班必須另外申請與核准。
- 加班費獨立於特殊上班日正常工時計算；核准後優先讀取當日特殊規則的加班級距，未設定時沿用一般加班規則。
- 沒有班別時間；正常工時由薪資作業依員工類型與已登記資料處理。
- 特殊上班日不要求先有排班，也不要求先有打卡，才可以套用或計薪。
- 固定每小時特殊薪資與時薪制倍率需要薪資結算的月度工時登記；月薪／日薪倍率直接依套用日期的底薪計算，不要求月度工時。
- 需要工時的特殊日當期缺少工時資料時，列為薪資異常，不自動猜測或補 0。
- 日期套用保存補貼項目名稱與套用數量；重新試算依目前規則的補貼單價計算，並計入當期應發與應付薪資。
- 第一版不設定補貼是否納入勞健保或課稅，也不處理其投保與課稅影響。
- 特殊規則套用不等於已打卡，也不等於加班已核准。
- 日期套用不可指定規則版本；規則版本僅供設定歷程與目前設定解析。

## 7. 歷史快照

套用到員工日期時保存最小關聯資料：

- 規則 ID
- 員工／支援人員與工作日期
- 各補貼的套用數量
- 套用者與套用時間

重新試算時依規則 ID 解析目前有效的薪資設定、加班級距與補貼單價。試算來源快照記錄本次使用的設定；補貼計算結果保存為獨立薪資明細，包含補貼項目、單價、套用數量與金額。

日後規則主檔變更不會改寫已結算的薪資明細；未結算批次若來源規則變更，結帳前必須重新試算。只要日期套用 ID 已出現在薪資來源快照或薪資明細，該套用與所屬規則就不能物理刪除。

## 8. 核心產品決策

1. 適用對象可以由 HR 自訂。
2. 補貼數量可輸入 0 或正整數，不設上限。
3. 特殊上班日以當日底薪計算應發總額，固定金額按每小時計算；薪資明細保留本薪，另列特殊日與原本薪資的差額。
4. 加班另外申請，系統獨立計算當日加班費；特殊上班日加班級距優先於員工平日加班規則，級距以 0.5 小時為單位，可使用倍率或固定每小時金額。
5. 同一員工同一天以日為單位只能套用一個特殊上班日規則。
6. 固定每小時特殊薪資與時薪制倍率的實際工時由薪資結算的月度工時登記提供；月薪／日薪倍率依套用日期的底薪計算。

## 9. 例外

- 同一員工同一天已有特殊規則：拒絕新增或編輯到另一筆已有紀錄；編輯目前這筆紀錄本身不算重複。
- 規則已停用：不可新增套用；既有紀錄可查看與維持原規則編輯，但不能改套到另一個停用規則。
- 日期套用尚未進入薪資試算版本：可刪除單筆套用；刪除規則時也會一併刪除這些尚未進入歷史的套用。
- 日期套用已進入薪資試算版本：不可刪除；所屬規則也不可刪除，必須改用停用。
- 員工已離職或支援人員已停用：不可套用到無效日期。
- 補貼數量不是正整數或 0：拒絕保存。

## 10. 權限

- 查看特殊上班日規則：出勤設定讀取權限。
- 建立、編輯版本、編輯日期套用、刪除尚未納入薪資試算的套用／規則、停用與套用：出勤設定寫入權限。
- 薪資金額與計算明細：全平台 HR 管理者。
