# 執行 PRD：特殊上班日規則

## 1. 目的

特殊上班日用來建立可重複套用的命名規則，並將規則套用到指定員工的指定日期。規則主檔與日期套用紀錄分開保存，計薪時使用當次套用的設定快照。

範例：

```text
常駐規則主檔：夜間進／撤櫃

有需要時才執行指派：
→ 員工：王小明、李小華
→ 日期：2026-08-05、2026-08-12
→ 補貼數量：各日期由 HR 登記
```

建立規則主檔時不選員工、不選日期；員工與日期只在「指派」時選擇。

## 2. 導覽

```text
HRIS
└─ 出勤管理
   └─ 特殊上班日
```

特殊上班日放在出勤管理，因為它首先定義日期的出勤性質；薪資結算讀取規則並計算金額。

## 3. 頁面結構

```text
特殊上班日
├─ 規則主檔
└─ 日期套用紀錄
```

### 規則主檔

列表顯示：

- 規則名稱
- 適用期間
- 已指派人數／日期摘要
- 薪資方式
- 加班設定摘要
- 啟用／停用狀態

操作：

- 新增規則
- 建立新版本
- 解除最新版本
- 停用規則
- 套用到員工日期

歷史規則不可直接覆寫；變更規則需建立新版本。若最新版本填錯，可依序解除最新版本回到上一版；第一版沒有可回復的版本，整份規則應改用停用。解除不刪除資料，已套用日期的規則快照與已結算薪資不受影響。

### 日期套用紀錄

列表顯示：

- 員工
- 日期
- 使用規則名稱與版本
- 固定每小時金額／倍率
- 補貼數量
- 套用者與套用時間

## 4. 規則欄位

| 欄位 | 必填 | 說明 |
|---|---:|---|
| 規則名稱 | 是 | 例如「夜間進／撤櫃」 |
| 適用對象 | 否 | 規則主檔不設定；於指派時選擇員工／支援人員 |
| 適用期間 | 是 | 規則版本的有效期間 |
| 薪資方式 | 是 | 特殊上班日薪資取代當日底薪 |
| 固定金額 | 否 | 以每小時計算 |
| 倍率 | 否 | 依確認的薪資公式計算 |
| 特殊日加班費級距 | 否 | 可依加班時數設定倍率或固定每小時金額；未設定時沿用一般加班規則 |
| 補貼項目 | 否 | 可設定多筆，例如夜間補貼、伙食補貼；套用日期時再填寫本次數量 |
| 備註 | 否 | 補充說明，可留空 |

特殊日加班費級距以 0.5 小時為單位保存，前端以累計加班時數的半開區間設定，起始含、迄止不含；例如 0.0～2.0 小時使用總倍率 150%，2.0 小時起固定每小時 NT$350。最後一級迄止留空代表從起始時數起不限時數；級距不可重疊或留空段。未設定級距時，核准加班沿用員工／公司加班規則。

固定金額與倍率的實際使用方式必須符合已啟用的薪資規則，不由前端自由組合出未定義公式。

## 5. 指派流程

規則主檔建立或維護時不指定員工與日期；有需要時從規則列按「指派」：

```text
選擇規則版本
→ 選擇一位或多位員工／支援人員
→ 選擇一個或多個日期
→ 輸入各日期補貼數量
→ 預覽
→ 套用
```

套用畫面提供：

- 員工複選
- 日期複選
- 每個員工／日期的補貼數量
- 預計影響人數與日期數
- 已存在套用紀錄提示

補貼數量：

- 可輸入 0 或正整數。
- 不設上限。
- 數量不是固定由規則主檔決定，套用時可依員工與日期輸入。

## 6. 計薪規則

- 特殊上班日薪資取代當日基本薪資，不是另外加在基本薪資上。
- 固定特殊薪資以每小時計算。
- 加班必須另外申請與核准。
- 加班費獨立於特殊上班日正常工時計算；核准後優先讀取當日特殊規則的加班級距，未設定時沿用一般加班規則。
- 沒有班別時間；正常工時由薪資作業依員工類型與已登記資料處理。
- 特殊上班日不要求先有排班，也不要求先有打卡，才可以套用或計薪。
- 特殊上班日的實際工時統一由薪資結算的月度工時登記提供。
- 當期缺少特殊上班日工時資料時，列為薪資異常，不自動猜測或補 0。
- 第一版補貼保存項目、單價與套用數量，並計入當期應發與應付薪資。
- 第一版不設定補貼是否納入勞健保或課稅，也不處理其投保與課稅影響。
- 特殊規則套用不等於已打卡，也不等於加班已核准。

## 7. 歷史快照

套用到員工日期時，必須保存：

- 規則 ID
- 規則版本（包含特殊日加班級距）
- 規則名稱快照
- 薪資設定快照
- 補貼設定快照
- 補貼數量
- 套用者與套用時間

補貼計算結果保存為獨立薪資明細，包含補貼項目、單價、套用數量與金額。

日後規則主檔變更或停用，不得改變已套用日期的歷史計薪結果。

## 8. 核心產品決策

1. 適用對象可以由 HR 自訂。
2. 補貼數量可輸入 0 或正整數，不設上限。
3. 特殊上班日薪資取代當日底薪，固定金額按每小時計算。
4. 加班另外申請，系統獨立計算當日加班費；特殊上班日加班級距優先於員工平日加班規則，級距以 0.5 小時為單位，可使用倍率或固定每小時金額。
5. 同一員工同一天以日為單位只能套用一個特殊上班日規則。
6. 特殊上班日的實際工時統一由薪資結算的月度工時登記提供。

## 9. 例外

- 同一員工同一天已有特殊規則：拒絕再次套用，必須先處理原套用紀錄。
- 規則已停用：不可新增套用，但可查看歷史。
- 員工已離職或支援人員已停用：不可套用到無效日期。
- 補貼數量不是正整數或 0：拒絕保存。

## 10. 權限

- 查看特殊上班日規則：出勤設定讀取權限。
- 建立、編輯版本、停用與套用：出勤設定寫入權限。
- 薪資金額與計算明細：全平台 HR 管理者。
